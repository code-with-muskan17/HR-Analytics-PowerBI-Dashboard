# 🧠 HR Analytics Dashboard (Power BI)

📌 **Project Overview**  
Interactive HR Analytics Dashboard developed in **Power BI** to analyze and understand **employee attrition patterns**.  
This project showcases the complete BI lifecycle—data preparation, data modeling, DAX-based KPIs, and visual insights—to support **data-driven HR and workforce planning decisions**.

---

## ✅ Key Highlights

- Cleaned and prepared raw data (handled missing values, formatted columns, removed duplicates)
- Designed the data model and created relationships between tables
- Built DAX measures for key KPIs:
  - Total Employees  
  - Total Attrition  
  - Attrition Rate
- Created visual insights to analyze attrition by:
  - Job Role, Education, Age Group, Salary Slab, Years at Company, Gender
- Used interactive slicers (Department & Gender) for drill-down analysis
- Applied custom background and visual formatting for a clean dashboard layout
